# Changelog

Todos los cambios notables de este proyecto se documentarán en este archivo.

El formato está basado en [Keep a Changelog](https://keepachangelog.com/es-ES/1.0.0/).

## [1.0.0] - 2024-06-06

### Added
- 🎉 Versión inicial del wrapper Android
- 🌐 WebView completo con soporte para app.all-hands.dev
- 📱 Diseño Material Design con tema de OpenHands
- 🔗 Deep linking para URLs de OpenHands
- 🔐 Soporte OAuth para GitHub, GitLab, Bitbucket
- 🚀 GitHub Actions CI/CD para builds automáticos
- 📦 APK debug artifact en cada release
- 🎨 Iconos personalizados para Android
- ❌ Manejo de errores con pantalla de reintento
- 🔄 Historial de navegación (botón atrás funcional)
- 💾 Caché y almacenamiento local habilitado
- 🔒 Aceptación de cookies de terceros

### Known Issues
- El APK requiere permisos de Internet
- Algunas funcionalidades web pueden requerir JavaScript
- La app necesita conexión a internet para funcionar

# Security Policy

## ⚠️ Aviso de Seguridad Importante

Este es un **wrapper no oficial** para OpenHands. Aunque nos esforzamos por mantener el código seguro, este proyecto:

1. **NO es afiliado** con All-Hands-AI
2. **NO ha sido auditado** por el equipo de seguridad de OpenHands
3. **Usa WebView** que puede tener vulnerabilidades

## 🔒 Recomendaciones de Seguridad

### Para usuarios:
- ✅ Instala solo APKs de fuentes confiables
- ✅ Verifica los permisos de la app antes de instalar
- ✅ Mantén tu dispositivo Android actualizado
- ✅ No compartas credenciales en redes no seguras

### Para desarrolladores:
- ✅ Revisa el código antes de compilar
- ✅ Usa el APK release para producción (no debug)
- ✅ Configura ProGuard/Obfuscation en releases

## 📋 Permisos de la App

La app solicita los siguientes permisos:

| Permiso | Uso |
|---------|-----|
| `INTERNET` | Conexión a app.all-hands.dev |
| `ACCESS_NETWORK_STATE` | Verificar conexión |
| `CAMERA` | (Opcional) Para funciones de OpenHands |
| `RECORD_AUDIO` | (Opcional) Para funciones de OpenHands |

## 🐛 Reportar Vulnerabilidades

Si encuentras una vulnerabilidad de seguridad:

1. **NO** uses el tracker de issues para reportes de seguridad
2. Contacta directamente al desarrollador
3. Proporciona detalles sobre la vulnerabilidad

## 📜 Términos de OpenHands

El uso de esta app está sujeto a los [Términos de Servicio de OpenHands](https://www.all-hands.dev/terms) y su [Política de Privacidad](https://www.all-hands.dev/privacy).
